# Experimental results

The experimental methodology and source code are documented in [the experiments directory](../code/experiments/README.md). The [software guide](../docs/SOFTWARE_GUIDE.md) explains the architecture and differentiates source-level checks, host emulation and hardware-dependent testing.

Results cited in the thesis should be traced to the relevant experimental scripts, parameters, execution environment and recorded outputs; numerical claims must not be inferred from source code alone.
