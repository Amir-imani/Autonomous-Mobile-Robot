# Raspberry Pi Pico Carrier / Header Board

This directory contains the hardware design files for the custom Raspberry Pi Pico carrier/header board used in the mobile robot.

## Directory structure

- `source/` — editable KiCad project, schematic, and PCB layout.
- `fabrication/gerber/` — copper, solder mask, solder paste, silkscreen, board outline, and Gerber job files.
- `fabrication/drill/` — plated and non-plated drill files.
- `images/` — top and bottom 3D renders plus a PCB Editor layout view.

## Design role

The board serves as the Raspberry Pi Pico interface/carrier for the robot electronics. It breaks out the Pico I/O and power rails through labeled connectors for the robot subsystems and provides the physical integration point between the RP2040 controller and the low-level electronics.

The editable KiCad sources are the authoritative design files. The Gerber and drill files are manufacturing outputs generated from this design snapshot.

## Fabrication snapshot

The supplied Gerber and drill outputs were generated by **KiCad/Pcbnew 10.0.3** on **2026-09-11**.

Before ordering a new production batch, open the project in KiCad, run ERC/DRC, verify the footprints and component selections, and regenerate the fabrication outputs if the source design has changed.
