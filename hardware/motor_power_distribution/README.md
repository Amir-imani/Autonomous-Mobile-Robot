# Motor Power Distribution Board

This board distributes fused supply power to the robot's drive system and provides connections for an INA-series measurement module. It is a power-distribution board, not the BTS7960 motor driver or embedded motor-control firmware.

- [KiCad schematic](source/Motor_P_robot.kicad_sch)
- [KiCad PCB](source/Motor_P_robot.kicad_pcb)
- [KiCad project](source/Motor_P_robot.kicad_pro)

## Manufacturing

Use the editable project as the source for ERC/DRC, pinout review, fabrication outputs and component verification. Check the current-monitor interface and power connector orientation against the as-built robot.
