# Motor Power Distribution Board

Custom PCB for routing and fusing motor power and connecting a current/voltage measurement module (INA-series monitoring module), designed in KiCad.

The circuit is part of the power distribution and measurement hardware; it is **not** the BTS7960 motor control firmware or the controller itself.

## Files
- `source/Motor_P_robot.kicad_pro`
- `source/Motor_P_robot.kicad_sch`
- `source/Motor_P_robot.kicad_pcb`

## Documentation status

Only editable KiCad design sources were provided. Gerber, drill, BOM, assembly drawings and photographs are not included. Before manufacturing, run ERC/DRC and verify connector and INA module pinouts.
